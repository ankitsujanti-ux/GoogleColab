Agent Flow & Sequence
Autonomous Decision Pipeline
1
Data Quality Agent
Validates & normalizes patient records, checks consent flags, computes refill timing
{arrow}
2
Adherence Risk Agent
Assesses risk score (0–100), labels (High/Medium/Low), signals, confidence
{arrow}
3
Escalation Decision Agent
Evaluates if patient requires clinician escalation based on risk thresholds and refill status
{arrow}
4
Orchestration Agent
Coordinates decision-making, routes to specialized agents, executes actions
4a
Consent & Routing Agent
Determines contact channel (SMS/Email/Pushover), validates consent
4b
Safety & Throttling Agent
Enforces daily caps, per‑patient cooldowns, policy gates
4c
Messaging Agent
Generates personalized notification messages via AI
{arrow}
5
Audit & Compliance Agent
Logs all decisions, tracks notification status, maintains audit trail for governance
🤖 Governance
All 5 agents operate autonomously with policy gates, consent checks, and throttling limits. Decisions are logged for auditability.
